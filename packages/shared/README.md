# @operza/shared

Shared TypeScript domain types, data contracts, DTO schemas, and utility constants used across the Operza monorepo (`apps/api`, `apps/web`, `packages/workflow-engine`).

---

## 📦 Contents

- **Domain Entities:** `Contact`, `Opportunity`, `Pipeline`, `Task`, `Appointment`, `Invoice`, `Document`, `Workflow`, `User`, `Location`, `Agency`.
- **Workflow Graph Types:** `WorkflowNode`, `WorkflowEdge`, `NodeType`, `NodeData`, `ExecutionState`.
- **Page Builder Types:** `BuilderElement`, `PageLayout`, `BlockType`, `ViewportSize`.
- **API Payloads & Contracts:** Request and response schemas for REST endpoints and WebSocket events.
