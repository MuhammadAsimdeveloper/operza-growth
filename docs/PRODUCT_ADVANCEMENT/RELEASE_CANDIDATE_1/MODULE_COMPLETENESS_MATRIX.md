Status classification per Stage 19 specification:
- **Verified:** Implementation + automated tests or browser interactions provide sufficient evidence.
- **Partially verified:** Core functionality works locally, but external providers or distributed infrastructure remain unverified.
- **Implemented, not verified:** Code exists, adequate functional verification is missing.
- **Unavailable:** Feature requires missing infrastructure, configuration, or provider access.
- **Defective:** Confirmed functional defect.
- **Not applicable:** Outside current product scope.
