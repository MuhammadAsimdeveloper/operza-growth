# External Provider Readiness Matrix

No external network calls were made and no live provider credentials were used. Statuses reflect code inspection and local deterministic contract tests only.

| Provider / Infrastructure | Classification | Basis / Observed Evidence | Staging / Production Requirement |
| --- | --- | --- | --- |
| **Stripe** | **Adapter implemented / Credentials absent / Sandbox not verified** | `stripePaymentAdapter` verified with deterministic unit/contract tests (`Idempotency-Key`, fail-closed on invalid creds). Legacy connector returns `403 PAYMENTS_DISABLED_PENDING_COMPLIANCE`. | Configure `STRIPE_SECRET_KEY`, `STRIPE_WEBHOOK_SECRET`, run live Stripe test-mode webhook & refund sandbox verification. |
| **Email (Resend / SendGrid)** | **Adapter implemented / Credentials absent / Sandbox not verified** | `Resend` and `SendGrid` adapters contract-tested; E2E Test 86 verifies invalid key fails closed (`400 PROVIDER_VERIFICATION_FAILED`). | Configure `RESEND_API_KEY` or `SENDGRID_API_KEY` + `SENDGRID_WEBHOOK_KEY`, verify SPF/DKIM/DMARC & bounce webhooks. |
| **Twilio (SMS & Voice)** | **Adapter implemented / Credentials absent / Sandbox not verified** | Twilio SMS & Softphone contract-tested; webhook signature verification implemented. | Configure `TWILIO_ACCOUNT_SID`, `TWILIO_AUTH_TOKEN`, `TWILIO_CALLER_ID`, `VOICE_SESSION_SIGNING_SECRET`, A2P 10DLC registration. |
| **WhatsApp / Meta Cloud API** | **Adapter implemented / Credentials absent / Sandbox not verified** | Meta Graph adapter contract-tested; `META_GRAPH_API_VERSION` supported. | Configure Meta Business App, verified phone ID, and webhook verify token. |
| **Google OAuth / Calendar** | **Adapter implemented / Credentials absent / Sandbox not verified** | OAuth & 2-way calendar sync tested with `TEST_GOOGLE_JWKS` / local mocks (`test-e2e.mjs` Test 105). | Register production `GOOGLE_CLIENT_ID` / `GOOGLE_CLIENT_SECRET` & authorized redirect URIs. |
| **Microsoft OAuth / Outlook** | **Adapter implemented / Credentials absent / Sandbox not verified** | Outlook connection passes tenant vault reference to adapter (`@operza/platform-core` unit test). | Configure `MICROSOFT_CLIENT_ID`, `MICROSOFT_CLIENT_SECRET`, `MICROSOFT_TENANT_ID`, `MICROSOFT_REDIRECT_URI`. |
| **AI Model Providers (OpenAI / Anthropic / Gemini / Ollama / LocalAI)** | **Adapter implemented / Credentials absent / Sandbox not verified** | `ai-provider.mjs` implements all 5 adapters; local model router & Copilot governance verified without live LLM calls. | Supply `OPENAI_API_KEY` / `ANTHROPIC_API_KEY` / `GEMINI_API_KEY` or self-hosted `OLLAMA_BASE_URL`. |
| **DNS & Custom Domain SSL** | **Configuration incomplete / Sandbox not verified** | Domain verification & site routing implemented in `domains.mjs` / `sites2.mjs`; no live DNS/ACM certificate issuance locally. | Configure CloudFront/ACM or Cloudflare for SaaS custom-hostname TLS automation. |
| **ClamAV / File Scanning** | **Configuration incomplete / Credentials absent** | Upload scanner integration checks `CLAMAV_BIN` & `CLAMAV_REQUIRED`; binary absent on local Windows host. | Deploy ClamAV sidecar/ECS service in staging and set `CLAMAV_REQUIRED=true`. |
| **Redis / BullMQ** | **Adapter implemented / Distributed cluster not verified** | Local execution uses in-memory fallback when `REDIS_URL` is unset; CI Gate 3 tests against single `redis:7-alpine`. | Provision ElastiCache Redis in staging and set `REDIS_URL` + `DISTRIBUTED_RATE_LIMIT_STRICT=true`. |
| **Object Storage (S3)** | **Configuration incomplete** | Local media/uploads use local filesystem paths; AWS blueprint specifies private S3 + SSE-KMS. | Provision private S3 bucket with OAC/presigned URLs before multi-instance staging. |
